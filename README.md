# The Shared Brain

A human-AI cognitive partnership system built by Marco Strohmkatigbak.

## What is this?

The Shared Brain is a three-layer knowledge and memory system that combines:
- **Open Brain** (Supabase) — the vault. Raw knowledge, source documents, meeting transcripts, established truths. Immutable and queryable.
- **Obsidian Wiki** — compiled understanding. Generated from the vault. Reflects how I think, not just what I know.
- **Notion** — operational workflow. Tasks, projects, client management. Where work happens.

Claude is the nervous system connecting all three.

## Why does this exist?

Most professionals carry their methodology in their head. Knowledge walks out the door when memory fades. This system is designed so that every project compounds on the last — nothing starts from zero.

It is also the skeleton of an AI-native consultancy. The same infrastructure that serves a solo consultant today becomes the onboarding system, methodology, and institutional memory of a growing firm.

## Three operating principles

1. **Lean contradiction resolution** — address errors the moment they surface, never let them compound
2. **Versioned thinking** — capture the arc of learning, not just the current state
3. **Building in public** — content creation and knowledge capture are the same motion

## Three capture modes

1. **Auto-summarization** — documents, videos, repos processed automatically on ingestion
2. **Pure chat capture** — the conversation itself is the source, insights saved at session end
3. **Doc-in-conversation** — discussing a document produces linked annotations saved beside it
