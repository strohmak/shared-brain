# Shared Brain — Project Lifecycle

## The Kaizen Principle
Every project compounds on the last. Nothing starts from zero.
The system gets smarter as the business grows.

## The Lifecycle

### 1. Initiation
- Notion task and project created
- First chat session — brief and context set
- Chat tagged to Notion project ID
- AI loads relevant context from vault

### 2. Active Work (repeating loop)
- Chat session → output
- Notion updated with decisions
- Insights flagged mid-session
- Lean contradiction resolution applied throughout

### 3. Completion Package
- Documentation produced
- Video walkthrough recorded
- Audio / transcript saved
- All session chats included
- Graduation review triggered

### 4. Graduation to Vault
One question: what from this project is worth remembering permanently?

What gets graduated:
- Full completion package (docs · video · audio · transcript)
- Flagged mid-session insights
- Versioned learning entries (what changed and why)

## The Graduation Trigger
At the end of every project or significant milestone, one question:
"Did anything happen here that's worth remembering permanently?"

If yes → capture it together → save to Supabase vault.

## What Gets Built Over Time

### Horizon 1 — Solo consultant
- Personal memory and faster execution
- Content engine fueled by project work
- Methodology refined with each engagement

### Horizon 2 — Small team
- Onboarding system for new hires
- Shared methodology across the team
- Quality standard maintained by the vault

### Horizon 3 — Scalable firm
- Institutional memory that doesn't walk out the door
- Productized service built on proven methodology
- AI-native by design from day one

## The Project ID Thread
Every Notion project gets an ID.
Every chat session related to that project gets tagged with that ID.
Every file in the completion package carries that ID.
When it all graduates to Supabase, the entire story of that project
— the thinking, the work, the output, the lessons — is linked and 
retrievable as one coherent package.

That's not just memory. That's your portfolio.
That's your case study library.
That's the raw material for every piece of content you'll ever make.
